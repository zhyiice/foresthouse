# 静林 · 木屋 — Forest Cabin

一座深林中的木屋。全部模型、材质、天空、植被、屋内陈设与大气效果均在浏览器中 **实时程序化生成**，
不使用任何外部贴图或模型文件（仅依赖 three.js 一个库文件）。

> 作品定位：可交互的实时电影感场景（WebGL / Three.js），面向三维场景与实时渲染类竞赛。
> 针对比赛演示机配置不一：内置 **显卡探测 + 低/中/高画质分级 + 帧率自动降档**。

---

## 一、运行方式

**推荐：直接双击 `index.html`**（无需服务器、无需安装依赖、可离线运行）。

也可以双击 `start.bat`，或用任意静态服务器打开。

目录要求：`index.html` 与 `three.min.js` 必须放在同一目录。
推荐浏览器：Chrome / Edge / Firefox 最新版（需 WebGL2）。

首次进入会有数秒的程序化生成过程，随后淡入。**低配电脑无需任何设置**：程序会识别显卡型号，
自动选择画质；运行中若帧率持续低于 30fps 会自动降档（降分辨率、阴影精度、植被与粒子数量、关闭光束），
帧率恢复后会自动升回。

## 三、声音

* **没有音频文件**：整个过程用 Web Audio 实时合成——一层缓慢的 Pad 和声（Dmaj9 → Bm9 → Gmaj9 → Aadd9，每 17 秒换一次，
  交叉淡入淡出）、一条低音持续音、偶尔的钟琴音（五声音阶，随机左右声道）、以及很轻的滤波风声。
* **会跟着时间走**：白天音色偏亮，黄昏变暖，夜里更暗更闷，切时段时会慢慢过渡（`src/js/13_audio.js` 里的 `followTime`）。
* **第一次打开会询问**：弹一个小卡片「要打开声音吗？」。选「开启」——音乐淡入 4.5 秒，同时自动弹出右上角的声音面板并高亮，
  告诉你滑杆在哪；选「保持静音」——只留一句提示，随时点右上角喇叭图标再开。之后不再打扰。
* **音量与开关**：右上角喇叭图标 = 面板开关；面板里是音量滑杆 + 静音按钮；音量与静音状态会记住（localStorage）。
* 浏览器不允许网页自动出声，所以一定要点一下才会响，这是正常现象。

## 四、场景内容

**木屋（数万三角面，全部手工程序化搭建）**

* 手工开槽的原木墙体：每根原木独立成段，门窗洞口真实开洞、转角出挑
* 山墙由逐层缩短的原木叠成，屋脊梁、檩条、椽子、封檐板
* 双坡木瓦屋顶：约 570 片独立瓦片，随机错缝、色差与苔藓；烟囱穿屋面处有金属泛水
* 石砌烟囱 + 烟囱帽 + 铁皮烟道，并有持续升腾的炊烟
* 门廊：木地板、立柱、斜撑、栏杆与栏板、台阶、吊灯、长椅、木桶、柴堆、斧头与砧木
* 石砌基础、门槛石、墙根苔石；门窗框深度按原木直径放大，不再陷进墙里
* 5 扇带窗棂的木窗（半透明玻璃可看见屋内），半开的木门与铁艺门把

**屋内（可走进去）**

* 木地板、天花与横梁、地毯
* 石砌壁炉：独立砌块、炉膛、柴火、四层火焰面片、余烬、壁炉火光、壁炉架与蜡烛/书本
* 餐桌 + 两把椅子 + 碗/杯，木床 + 被子 + 枕头 + 床头板
* 置物架与罐子、柴箱、窗帘（带褶皱）、窗台绿植、吊灯

**森林**

* 3 级 LOD 的针叶林（近景细节树 / 中景 / 远景林线，600+ 棵）
* 用「针叶喷簇」透明贴图卡片构建树冠，带风场摆动
* 白桦与秋色阔叶树，叶片卡片 + 程序化枝干
* 12,000 丛草、210 株蕨类、95 株灌木、85 块岩石
* 倒木、树桩、蘑菇、落叶、林间小径与踏石、木栅栏、石火塘

**天气与季节**

* 6 种天气：晴朗 / 薄雾 / 浓雾 / 雨 / 雪 / 雷暴。雨是 GPU 粒子雨丝，雪是带摆动的絮状雪片，
  雷暴会在 4–12 秒间随机闪一次电（天先亮、后打雷，雷声是合成的低频轰鸣）。
* 4 个季节：春 / 夏 / 秋 / 冬。冬天雪会积在屋顶、地面和土路上，草与蕨被雪盖住，阔叶树落叶，
  光线偏冷；秋天阔叶变黄。雪与季节切换是平滑过渡的。
* 门窗跟着季节走：夏天半开、冬天关上；也可以左上角天气条里手动设「关 / 半开 / 全开」。
  窗是上下开合的悬窗，门是能开合的。

**大气与光照**

* 自定义大气散射天空：垂直渐变、日/月盘、日晕、霞光、体积云、夜空星野与银河
* 指数高度雾 + 34 片体积雾气精灵（薄雾/浓雾差异明显）
* 屏幕空间丁达尔光束（遮挡掩膜 → 径向散射 → 合成），黄昏/黎明穿过树冠形成光柱
* 萤火虫粒子（220 只，独立闪烁相位与漂移）、空气尘埃、飘落树叶、炊烟
* 多级泛光 + ACES 影调映射 + 分离色调 + 暗角 + 色差 + 胶片颗粒 + 抖动

## 五、性能设计（重点）

* **画质三档**（`src/js/00_quality.js`）

  | | 低 | 中 | 高 |
  |---|---|---|---|
  | 渲染分辨率上限 | 0.85× | 1.25× | 1.8× |
  | 阴影贴图 | 1024 | 2048 | 4096 |
  | MSAA | 关 | 2× | 4× |
  | 泛光层数 | 2 | 3 | 3 |
  | 丁达尔光束 | 关 | 开 | 开 |
  | 草 / 蕨 / 灌木 | 3400 / 70 / 40 | 7200 / 140 / 65 | 12000 / 210 / 95 |
  | 中景树 / 远景树 | 62 / 240 | 100 / 360 | 130 / 430 |
  | 萤火虫 / 尘埃 / 雾片 | 90 / 110 / 10 | 150 / 190 / 20 | 220 / 300 / 34 |
  | 植被投影 | 关 | 开 | 开 |

* **显卡探测**：读取 `WEBGL_debug_renderer_info`，按 Intel / AMD / NVIDIA / Apple / Mali / SwiftShader 等
  分档，再结合核心数与屏幕分辨率修正；识别失败默认中档。
* **运行期自适应**：预热 3 秒后统计帧率，连续 2 秒低于 30fps 立即降一档；稳定 45fps 以上再逐级升回。
* 低档下所有实例数量、粒子数量、后处理层数都会减少，几何体数量不变（不重建场景，切换瞬时完成）。
* 全场景约 600k 三角面、约 250 个 draw call；植被全部 InstancedMesh；桌面像素比上限 1.8、手机 1.35。
* 手机端另有独立档位（`Q.MOBILE_PROFILE`），整体约为桌面低档的 1/4–1/5。

## 六、技术要点

* **零外部资源**：所有木纹、树皮、石墙、瓦片、地表、针叶、树叶、蕨类、雾气、地毯、被子、窗帘
  都是运行时用 Canvas 2D 程序化绘制；地形、树木、岩石、木屋与家具全部由代码生成几何体。
* **自定义渲染管线**（未使用 EffectComposer / 任何后处理插件）：
  1. 场景渲染到 HalfFloat + MSAA 的 HDR 缓冲
  2. 亮度提取 → 分离高斯 → 多级降采样泛光
  3. 屏幕空间丁达尔：太阳屏幕坐标 → 亮度掩膜 → 10 采样径向模糊 × 3 次
  4. 合成：色差 → 泛光 → ACES → 升降格调色 → 饱和/对比 → 暗角 → 颗粒 → sRGB
* **第一人称漫游**：自写圆-AABB 碰撞（墙、门洞、壁炉、床、桌、货架），地形与室内地板高度约束。
* **确定性**：所有随机数使用固定种子，每次加载的森林布局完全一致。

## 八、手机端与 GitHub Pages

**手机端**（自动识别，无需设置）：分辨率上限压到 1.35×、关多重采样、关光柱、泛光降到 1 层、
阴影 1024、草/树/粒子数量约为桌面的 1/5；竖屏时自动换更广的镜头、镜头距离拉远，
手指拖拽的灵敏度是鼠标的 1.9 倍，界面在窄屏下会收起「画质」并把右上角精简成两个按钮。
底部时间/天气面板会自动折成两行。

**部署到 GitHub Pages**（纯静态，不需要构建）：

1. 把 `forest-cabin` 目录里的内容（`index.html`、`three.min.js`、`src/`、`screenshots/`、`.nojekyll`）
   推到仓库根目录；
2. 仓库 → Settings → Pages → Source 选 `Deploy from a branch`，分支 `main`、目录 `/ (root)`，保存；
3. 等一两分钟，访问 `https://<用户名>.github.io/<仓库名>/` 即可。

所有资源都是相对路径、无外部请求、无后端，`.nojekyll` 已放好。`build.py` 和 `src/` 不是运行必需，
但一起传上去也方便别人改。

## 九、可调参数（给评委 / 二次创作）

* `src/js/00_quality.js` → `Q.TIERS`：三档画质的所有数量与开关
* `src/js/09_atmos.js` → `ATM.presets`：每个时段的太阳、雾、曝光、泛光、窗光、壁炉火光、粒子量、调色
* `src/js/09_atmos.js` → `ATM.weathers`：三档天气的雾密度、雾片数量、光束强度倍率
* `src/js/10_post.js` → 最终调色 uniform：暗角、颗粒、色差、泛光
* `src/js/05_trees.js` → `buildPine()` / `buildBirch()`：树的形态参数
* `src/js/06_cabin.js` → `W / D / eave / ridge / logR`：木屋尺度
* `src/js/06b_interior.js` → 家具尺寸与位置
* `src/js/13_audio.js` → 和弦进行（`AUD.chords`）、换和弦速度（`AUD.chordDur`）、钟声与风声的音量

调试参数：
`?q=0|1|2` 强制画质 · `?time=dusk&weather=mist&firefly=0` 指定初始状态 ·
`?still=4` 渲染单帧静帧（出图用）· `?cam=x,y,z&look=x,y,z` 指定机位
